# План полировки бридж-чата

Основание: ревью 1.21.44 (коммит `07065d1`) — код вебвью и хоста, инструменты,
визуальный проход по стенду, логи за 18–20 ноября. Ревью делали субагенты
GPT-6.1 Terra и GPT-6-Luna, находки с ✓ перепроверены по коду.
Статус: в работе. Начало: 2026-11-20.

## Правила выполнения

- Шаги ставятся исполнителям по `AGENTS.md`: Luna — мелкие (S), Terra — средние
  (M). Оркестратор проверяет каждый результат, запускает `npm run compile`,
  `npm run lint`, `npm test`, ведёт версию, CHANGELOG и VSIX.
- Каждый пакет — отдельный dev-патч с записью в CHANGELOG и обновлением
  `docs/CHAT.md`, где меняется поведение.
- Пункт отмечается выполненным только после проверки и зелёных тестов.
- Коммит — только по просьбе пользователя.
